《第三方SDK目录》（接入第三方SDK情况说明）

说明：以下为本游戏《变装战机2》接入的具有收集个人信息能力的全部第三方SDK/框架。所列隐私政策链接请以各官方最新公布版本为准，上架前请逐一核对。本游戏采用"同意门禁"：首次启动时由系统原生界面先展示隐私政策弹窗，用户点击同意之前，Unity 引擎与任何 SDK 都不会启动，不会读取任何设备信息。

──────────────────────────────
1. Unity 引擎框架
开发者全称：Unity Technologies ApS（Unity 中国：unity 中国有限责任公司）
使用目的：游戏运行与渲染引擎，生成设备运行环境标识以保障基础功能
使用场景：用户点击同意隐私政策后才启动；此后贯穿游戏运行全程
调用权限：网络访问
收集个人信息类型及方式：设备标识符（Android ID）、设备型号、系统版本、网络类型、设备传感器信息（加速度计、陀螺仪、磁力计等，用于屏幕方向识别与输入适配）；由引擎框架自动读取
隐私政策链接：https://unity.com/cn/legal/privacy-policy
频次时机：同意后引擎启动时读取并持续使用；同意前不读取

──────────────────────────────
2. TapTap 开发者服务 SDK（TapSDK：登录/云存档/排行榜/成就）
开发者全称：心动网络股份有限公司
使用目的：TapTap 账号登录、游戏存档云端同步、排行榜与成就
使用场景：用户点击登录、启动时恢复登录态、云存档同步时
调用权限：网络访问
收集个人信息类型及方式：TapTap 账号 open_id/union_id、昵称、头像、设备标识符（Android ID）、设备与网络信息；SDK 自动采集
隐私政策链接：https://developer.taptap.cn/docs/sdk/compliance/privacy/
频次时机：用户同意隐私政策后初始化一次；登录/同步时按需上报

──────────────────────────────
3. TapADN（Dirichlet）广告 SDK
开发者全称：心动网络股份有限公司
使用目的：激励视频广告加载、展示与奖励发放
使用场景：用户主动点击"观看广告"时
调用权限：网络访问
收集个人信息类型及方式：设备标识符（Android ID、OAID、GAID）、IP 地址、设备传感器信息（加速度计、陀螺仪等）、应用安装列表、广告交互记录（展示、点击、完成）、网络类型；SDK 自动采集
隐私政策链接：https://ssp.dirichlet.cn/
频次时机：用户同意隐私政策后初始化一次（用于广告预加载）；每次观看广告时请求并上报

──────────────────────────────
4. Unity Ads SDK（com.unity.ads 包）
开发者全称：Unity Technologies ApS
使用目的：广告备用通道（本版本未启用；SDK 的"进程启动自动初始化"入口已在打包时移除）
使用场景：仅在广告展示流程中按需使用
调用权限：网络访问
收集个人信息类型及方式：设备标识符（GAID）、IP 地址、广告交互记录（若启用）
隐私政策链接：https://unity.com/cn/legal/privacy-policy
频次时机：同意前与同意后均不初始化，不产生任何采集行为

──────────────────────────────
本游戏自身收集的信息（不属于第三方SDK）：
- 设备标识符（Android ID）：生成玩家唯一标识、存档与防作弊；
- 广告标识符（GAID/OAID）：广告投放、频控与反作弊；
- IP 地址：网络服务安全与防作弊；
- 设备型号、操作系统版本、网络类型：适配与故障排查；
- 游戏进度与存档数据：保存游戏进度并按账号云端同步。

──────────────────────────────
共享与披露说明：
- 除上述 SDK 外，本游戏不接入其他具有收集个人信息能力的第三方代码或服务。
- 本目录仅适用于 TapTap 渠道版本；Google Play 渠道版本的 SDK 披露见 privacy_policy_google.html。
