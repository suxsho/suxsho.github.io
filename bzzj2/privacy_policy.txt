《隐私政策》

版本生效日期：2026年10月30日
更新日期：2026年10月30日

一、引言
本隐私政策适用于Terobi独立游戏组（以下简称"我们"）开发运营的《变装战机2》（包名：com.terobi.hf2，以下简称"本游戏"）。本政策旨在向您说明我们如何收集、使用、存储和共享您的个人信息，以及您享有的相关权利。请您在使用本游戏前仔细阅读并充分理解本政策，特别是涉及个人信息处理的条款。您点击"同意"即表示您已阅读并同意本政策的全部内容。

二、我们收集的个人信息及目的、方式和范围
1. 设备标识信息（Android ID 等设备标识符）
   - 收集目的：生成玩家唯一标识（UID）、保存游戏进度归属、防止作弊与刷榜、广告投放与频控。
   - 收集方式：由本游戏及 Unity 引擎框架、TapTap SDK、广告 SDK 在您同意本政策后自动读取。
   - 收集范围：设备标识符（Android ID）、设备型号、操作系统版本。
   - 收集频次与时机：仅在您同意本政策后、首次启动登录流程及请求广告时读取；同意前不会收集。
2. 游戏存档与进度数据
   - 收集目的：保存您的游戏进度，并（在登录 TapTap 账号后）通过 TapTap 云存档同步到其他设备。
   - 收集方式：本游戏自动收集并上传至服务端。
   - 收集范围：关卡进度、金币、等级、成就、星星数等游戏内数据。
   - 收集频次与时机：游戏进程自动存档、登录成功及云存档同步时上传。
3. 第三方账号信息（TapTap 账号 / Google Play 游戏账号）
   - 收集目的：身份验证、排行榜、成就、云存档。
   - 收集方式：经您授权后由 TapTap SDK / Google Play Games SDK 返回账号唯一标识与昵称头像。
   - 收集范围：账号唯一标识（open_id/union_id/Google Player ID）、昵称、头像。
   - 收集频次与时机：仅在您点击登录/授权时获取。
4. 广告相关数据
   - 收集目的：向您展示激励视频广告、发放广告奖励、广告反作弊。
   - 收集方式：由 AdMob SDK / TapADN(Dirichlet) SDK 在广告请求与展示时自动收集。
   - 收集范围：设备标识符、广告交互记录（展示、点击、完成）、网络类型。
   - 收集频次与时机：仅在您主动点击"观看广告"时请求与上报。
5. 反馈信息
   - 收集目的：处理您的问题反馈。
   - 收集方式：您主动通过反馈渠道提交时，附带设备标识与游戏数据摘要。
   - 收集范围：反馈内容、设备标识符、昵称、游戏等级与进度摘要。
   - 收集频次与时机：仅在您主动提交反馈时。

除上述信息外，本游戏不收集您的通讯录、短信、相册、精确位置等其他个人信息。

三、权限说明
本游戏申请并使用以下系统权限：
- 网络访问（INTERNET / ACCESS_NETWORK_STATE / ACCESS_WIFI_STATE）：用于游戏联网、公告拉取、云存档与广告服务。
- 大致位置（ACCESS_COARSE_LOCATION）：仅用于广告地域定向。只有在您点击"观看广告"并在广告确认窗点"同意"之后才申请，可拒绝，拒绝后广告仍可播放与领奖。
- 电话状态（READ_PHONE_STATE）：仅用于广告反作弊，不读取通话内容、通话记录与通讯录，不拨打电话。申请时机同上，可拒绝，拒绝不影响游戏功能。
- 系统级普通权限（安装时自动授予、不弹窗）：广告标识（AD_ID）、广告服务、应用列表查询（QUERY_ALL_PACKAGES）、安装包安装（REQUEST_INSTALL_PACKAGES）、OAID 厂商标识服务（MSA）、前台服务与唤醒。
本游戏不申请存储、精确位置（ACCESS_FINE_LOCATION）、相机、麦克风、通讯录、短信等其他权限。关闭位置或电话权限后，本地游戏功能不受影响。

四、第三方 SDK 共享情况
为实现上述功能，本游戏接入了具有收集个人信息能力的第三方 SDK。各 SDK 的名称、开发者全称、使用目的、使用场景、调用权限、收集类型及方式、隐私政策链接、频次时机详见《第三方SDK目录》（与本政策同等重要，构成本政策的组成部分）。

五、信息的存储
1. 存储地点：您的游戏存档与账号数据存储在中华人民共和国境内（TapTap 云服务）或为您提供服务所必需的境外服务器（Google 服务）。
2. 存储期限：我们仅在本政策所述目的所必需的期间内保留您的个人信息；您注销账号后，我们将删除或匿名化您的个人信息。
3. 存储安全：我们采用加密传输（HTTPS）、访问控制等合理措施保护您的个人信息。

六、您的权利
1. 查阅与更正：您可以通过游戏内设置界面查看您的账号信息（UID、昵称）。
2. 删除与注销：您可以通过游戏内"设置-注销登录"发起账号注销；注销完成后我们将删除或匿名化您的个人信息。您也可以通过 TapTap/Google 账号体系删除授权。
3. 撤回同意：您可以停止使用本游戏，或通过卸载清除本地授权状态；撤回同意不影响撤回前基于同意已进行的处理。
4. 投诉举报：如您认为我们的个人信息处理行为损害了您的合法权益，您可通过本政策底部的联系方式向我们投诉，也可向有关政府部门举报。

七、未成年人保护
本游戏高度重视未成年人个人信息保护。若您为未成年人，请在您的监护人仔细阅读并同意本政策后，由监护人指导您使用本游戏。我们仅在法律允许或监护人明确同意的范围内处理未成年人的信息。本游戏接入的防沉迷与实名系统（如适用）按国家新闻出版相关规定执行。

八、政策更新
本政策更新后，我们将在游戏内以弹窗或公告方式通知您。重大变更（如处理目的、方式、范围变化）将重新征得您的同意。
